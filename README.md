# ComfyUI Portal\n\n- Flask 应用：登录、任务排队、进度、结果查看\n- 开发运行：\n  - python -m venv .venv && .venv\\Scripts\\Activate.ps1\n  - pip install -r requirements.txt\n  - copy .env.example .env 并按需修改\n  - python -m app\n\n目录\n- app/: 应用代码 (auth, jobs, pages)\n- workflows/: ComfyUI 工作流 JSON\n- uploads/: 上传临时文件\n- results/: 结果存储或索引\n- templates/: 简单前端\n\nAPI\n- POST /api/jobs (form: workflow, overrides JSON, files)\n- GET  /api/jobs/<id>/status\n- GET  /api/comfy/view?filename=...\n- GET  /api/queue\n
